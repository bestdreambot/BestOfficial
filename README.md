# BestOfficial

Официальная публичная страница — [bestofficial.vercel.app](https://bestofficial.vercel.app/)

## Что это

Золотое слово «BestOfficial» на чёрном фоне и кольцо из ~2200 движущихся частиц.
Клик по кольцу меняет его цвет. Клик по слову проводит по цепочке проектов —
у каждого шага свой цвет кольца и свой переход.

## Факты

- Текущий релиз: **1.2**
- Мир по умолчанию — серебро; клик по слову переводит в Best (золото)
- Слово всегда золотое — меняется цвет только у кольца
- Цепочка по клику на слово: 27 проектов, у каждого подтверждённый адрес (TikTok или YouTube),
  если он был подтверждён — иначе ссылка не показывается

# BestOfficial

Официальная публичная страница — [bestofficial.vercel.app](https://bestofficial.vercel.app/)

## Что это

Золотое слово «BestOfficial» на чёрном фоне и гранёный кольцевой Ктор из живых частиц/граней.
Клик по слову проводит по цепочке проектов — у каждого шага свой цвет кольца и свой переход
(portal/dissolve/wipe/burst/spiral). Слева и справа — младшие торы (mktor): левый ведёт в звёзд
Best (у каждой звезды свой цвет и фото), правый всегда золотой и ведёт домой.

## Факты

- Текущий релиз: **3.0**
- Слово всегда золотое — меняется цвет только у кольца/торов
- Цепочка по клику на слово: проекты, у каждого подтверждённый адрес (TikTok), если он был
  подтверждён — иначе ссылка не показывается
- «Звёзды» (левый mktor) — цепочка участников Best, у каждой свои фото, роли и цвет мира
- Открывается и как обычная страница, и как Telegram Mini App (тактильный отклик, ссылки через
  Telegram openLink, безопасные отступы под системный интерфейс)
